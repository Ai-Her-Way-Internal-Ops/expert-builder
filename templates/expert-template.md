# Generated expert pack contract
Create this in the user's chosen working folder, separate from the kit.

## AGENT.md
Name / owner / job / scope / excluded decisions / inputs / output / permitted tools / skill routing / source retrieval / escalation / working-record location.

## KNOWLEDGE.md
Knowledge date; principles [source IDs]; decision rules; exceptions; failure modes; competing views; worked examples; thin areas. Cite source IDs beside claims.

## SOURCES.md
| ID | Title and author | URL/file and location | Published/updated | Retrieved | Access/rights | Supports | Limitations |
|---|---|---|---|---|---|---|---|

## LIVE.md (only when needed)
Fact / source ID / checked date / expiry or refresh trigger / effect on recommendation.

## TASK-SKILLS.md
For each bounded task: trigger, required input, method, expected output, checks, tool dependencies and stop conditions.

## EVALUATION.md
Case / expected criteria / baseline result / expert result / evaluator / source support / correction time / pass or failure / repair. State which test cases the compiler saw. Do not treat disclosed answer-key examples as held-out evaluation.

## HANDOVER.md
Current stage / last verified outcome / file versions / unresolved gaps / next action / owner / review date / change history. State whether refresh and review are manual or have been tested in the runtime.
